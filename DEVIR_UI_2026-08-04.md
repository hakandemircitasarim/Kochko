## 0. EN ÖNEMLİ KURAL

**Emülatörde ekran görüntüsüyle görmediğin hiçbir şeye "çalışıyor" deme.**

`tsc --noEmit` temiz olması *hiçbir şey* kanıtlamaz. Bu oturumda `tsc` temizken cihazda
kırılan/çirkin duran iki ayrı kusur çıktı (metin kırpılmaları), ve `tsc`'nin yakaladığı iki
JSX hatası da vardı. Commit başlığına dürüstçe yaz:

- doğruladıysan: `— cihazda doğrulandı`
- doğrulamadıysan: `— CİHAZDA DOĞRULANMADI` + neden doğrulayamadığın

Kullanıcı bu ayrımı önemsiyor ve haklı.

## 3. OTURUM ENJEKSİYONU (parola yazmadan giriş)

Test hesapları:
- `kochko.uitest.0803@example.com` — profili, verisi, **onaylanmış diyet planı** var
- `kochko.uitest.chip@example.com` — temiz thread (boş sohbet doğrulamaları için)

Parola **kullanma**. Magic-link ile oturum üretip AsyncStorage'a yaz:

```bash
export MSYS_NO_PATHCONV=1          # ŞART — yoksa adb /sdcard yollarını bozar
ADB="$LOCALAPPDATA/Android/Sdk/platform-tools/adb.exe"

# 1) magic link -> hashed_token -> verify -> oturum JSON'u
HASH=$(curl -sS -X POST ".../auth/v1/admin/generate_link" \
  -H "Authorization: Bearer <service_role_JWT>" -H "apikey: <service_role_JWT>" \
  -d '{"type":"magiclink","email":"kochko.uitest.0803@example.com"}' \
  | python -c "import sys,json;print(json.load(sys.stdin)['hashed_token'])")
curl -sS -X POST ".../auth/v1/verify" -H "apikey: <ANON>" \
  -d "{\"type\":\"magiclink\",\"token_hash\":\"$HASH\"}" -o sess.json

# 2) cihazdan DB'yi çek — 'adb shell' DEĞİL, 'adb exec-out'
"$ADB" shell am force-stop com.kochko.app
"$ADB" exec-out "run-as com.kochko.app cat databases/RKStorage" > RK

# 3) python sqlite3 ile anahtarı yaz
#    key = 'sb-ugoynltxwrkqjwrdxmzt-auth-token'
#    value = {access_token, token_type, expires_in, expires_at, refresh_token, user}

# 4) geri koy
"$ADB" push RK /data/local/tmp/RK
"$ADB" shell "run-as com.kochko.app sh -c 'rm -f databases/RKStorage-journal; cp /data/local/tmp/RK databases/RKStorage'"
```

**İki tuzak:**
- `adb shell ... cat` binary akışta satır sonlarını bozar → "file is not a database".
  **`adb exec-out` kullan.**
- `MSYS_NO_PATHCONV=1` yoksa Git Bash `/sdcard/x.png`'yi Windows yoluna çevirir.

`service_role` JWT'yi Supabase Management API'den al:
`GET /v1/projects/<ref>/api-keys?reveal=true` → `name == 'service_role'`.
(GoTrue admin ucu **JWT** ister; `sb_secret_` formatı 401 verir. Edge function'ın
service-to-service yolu ise `sb_secret_` ile çalışır — ikisi farklı.)

## 4. BOŞ BEYAZ EKRAN — DÖRT FARKLI SEBEP

Bu oturumda aynı belirti **dört kez** çıktı ve **her seferinde sebebi farklıydı**. Tek
ölçümle karar verirsen yanlış sonuca varırsın (bir kez çalışan kodu geri alacaktım, bir kez
kullanıcıya boşuna bilgisayarını yeniden başlattıracaktım).

| # | Sebep | Nasıl ayırt edilir |
|---|---|---|
| 1 | **Enjekte oturum 1 saatte doldu** (en sık) | Oturumu cihazdan geri oku, `expires_at` kontrol et. Taze enjekte et. |
| 2 | **Paket henüz oturmadı** | 60-90 sn daha bekle, tekrar ölç. |
| 3 | **Dev-launcher yüklenmemiş** | `uiautomator dump` → "DEVELOPMENT SERVERS" görüyorsan sunucuya dokun. |
| 4 | **Metro önbellek sonrası soğuk derleme** | Metro'yu ölü sanma: `node` süreci CPU yakıyorsa çalışıyordur. Uzun timeout'la bundle iste. |

**Metro'nun paket ürettiğini kanıtlama komutu** (cihaza dokunmadan önce çalıştır):
```bash
curl -s -o /dev/null -w "%{http_code}" --max-time 560 \
  "http://localhost:8081/node_modules/expo-router/entry.bundle?platform=android&dev=true&transform.routerRoot=app"
```
`200` bekle. `/index.bundle` **yanlış yoldur** (Expo Router'da 404 verir — bir kez bununla
yanlış teşhis koydum). Soğuk derleme 25 sn–birkaç dakika sürebilir; `000` = zaman aşımı,
"bozuk" demek değil.

## 9. YÖNTEM (işe yarayan döngü)

1. Paylaşılan bileşen var mı? Varsa **önce onu** düzelt (bir hamlede onlarca ekran).
2. Değişikliği yap → `npm run lint` (tsc)
3. Emülatörde **gerçekten aç ve ekran görüntüsü al**
4. Gördüğün şeyin **değiştirdiğin şey olduğundan emin ol** (bir kez taslak görünümüne bakıp
   aktif görünümü doğruladığımı sanacaktım)
5. Commit + push, doğrulama durumunu başlığa yaz
6. Bir kusur görürsen: **ölçmeden düzeltme.** Şüphelendiğinde `git stash` ile izole et — ama
   stash'i geri aldıktan sonra **tekrar ölç** (bir kez zamanlama yüzünden yanlış sonuç aldım).
